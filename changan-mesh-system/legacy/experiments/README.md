# 实验记录约定

本目录只保留实验数据与记录约定；当前运行入口见 [运行说明](../../docs/operations.md)，功能与稳定性结论见 [验收状态](../../docs/status.md)。旧三板 results.csv 不能作为当前四角色或新固件的实测证据。

每次运行建立一个 `runs/<日期>-<实验编号>/` 本地目录，保存三端原始串口日志和实际生效的sdkconfig；该目录默认不进入Git。将去除无关内容的结果摘要及运行元数据保留在仓库，较大数据以后再决定外部归档或Git LFS。

至少记录：实验 ID、固件 commit、ESP-IDF 完整版本、`third_party/vendor-lock.json` 版本清单、各板身份/MAC/端口、拓扑配置、真实父子关系、信道、距离/遮挡条件、负载、统计窗口和结果。当前角色为 pc_root、ugv、uav、micro_uav，Micro 可有多个独立编号。未测业务吞吐时写“未测”，不要填 0。

首组结果建议为star入网、chain入网、auto中继失联恢复。加入TCP后再做单发／并发、直连／两跳及中继失效的组合。单向时延需要明确时钟同步方式；仅有本地时间戳时优先记录RTT，不能拿两个未同步节点的时间戳直接相减。

结果模板见 `results.csv`。预期结果与实际结果分开记录。
